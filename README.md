# CS-360 Mobile Architecture and Programming: Weight Tracking App

## Project Overview
The goal of this project was to develop a mobile weight tracking application that allows users to record and monitor their weight over time. The app was designed to provide a simple way for users to track their progress, view their weight history, and manage their personal goals. The main focus was creating an application that was functional and easy to use.

## User Interface Design
The application included screens for user login, entering weight information, viewing weight records, and managing user data. I focused on keeping the interface simple and organized so users could navigate the app without unnecessary steps. Input fields, buttons, and data displays were designed to make the main features easy to understand and use. These design choices helped create a straightforward user experience.

## Development Approach
I approached development by building the user interface and then implementing the code needed to make the different components function correctly. I learned that creating the visual elements is only one part of app development. The underlying code must also handle user input, button clicks, data storage, and navigation correctly. Breaking the project into smaller pieces made it easier to work through each feature and troubleshoot problems. I can apply this approach to future projects by developing and testing individual components before combining them into a complete application.

## Testing
I tested the application using the Android emulator to check that the screens displayed correctly and that the main features worked as intended. I checked user input, button functionality, and the application's interaction with stored data. Testing was important because a screen that looks correct does not necessarily mean the code behind it works correctly. This process helped me understand the importance of checking both the user interface and the application's functionality.

## Challenges and Innovation
One of the main challenges was connecting the interface to the underlying application logic. Buttons and input fields needed to perform the correct actions rather than simply look like they worked. Working through these challenges helped me better understand how the different parts of an Android application interact. I also learned the importance of making design decisions that balance functionality with simplicity.

## Skills Demonstrated
I was particularly successful in developing the user interface and connecting it to the application's functionality. This project helped me improve my understanding of Android development, event handling, user input, and data management. Although the application is relatively basic compared to commercially available weight tracking apps, it provided valuable hands-on experience with the complete mobile app development process and gave me a foundation I can build on in future projects.
